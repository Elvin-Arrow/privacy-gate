# Knowledge Governance Skill

An agent skill for maintaining a lightweight, navigable project knowledge architecture.

The skill deliberately scales with the project. A greenfield project can start with `docs/idea.md` and grow into specs, decisions, development logs, and indexes only when those structures become useful.

### Knowledge boundaries

- **Specs:** what is true now.
- **Decisions:** why important choices were made.
- **Dev logs:** meaningful implementation history.
- **Indexes:** how agents navigate the knowledge.
- **idea.md:** evolving early-stage thinking.

Copy the `knowledge-governance` directory into the skills directory used by your coding agent. `SKILL.md` is the entry point; templates are optional helpers.
